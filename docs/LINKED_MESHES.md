# 关联网格与独立皮肤变形

关联网格在同一个插槽内复用源网格的顶点、UV、三角形和骨骼权重，同时保留自己的图片引用。修改源网格后，预览和导出使用更新后的几何。工程文件只保存源引用，不重复写入一套共享几何。

## 建立关联

1. 在 Setup 模式选中目标图片或网格附件。源网格与目标必须处于同一个插槽；源也可以位于另一个皮肤中。
2. 在附件属性点击“关联到网格...”，选择“基础附件 / 名称”或“皮肤名 / 名称”。列表只显示有效网格，不能选择会形成循环的源。
3. 目标保留自己的图片，开始共享源网格的几何与权重。目标图片的比例和内容位置应与源的 UV 布局相适应；关联不会自动重新绑定另一种构图的图片。

若目标位于皮肤中，先启用目标皮肤、选中对应占位，并为该皮肤创建或复制一个附件，再建立关联。来源皮肤无需同时启用；链接按明确的来源定位。

## 源动画与独立动画

“继承源网格的变形动画”默认开启。开启时，目标跟随源的变形关键帧；在目标上不能直接拖动制作变形，应编辑源。

要制作独立动作，在 Setup 关闭继承，进入 Animate，选择目标附件，用网格工具 M 拖动顶点。新增关键帧只记录当前皮肤的目标；切换到另一皮肤不会使用这些新关键帧。两个皮肤可以使用不同顶点数量和各自的变形动画。

在属性里“删除当前帧的变形关键帧”只删除当前皮肤的关键帧。Dopesheet 仍按插槽附件汇总时间点：同一附件、同一时间的多个皮肤关键帧显示为同一个标记，整行移动、复制或删除会一起处理它们。需要只修改某一皮肤时，使用该皮肤的视口变形与属性删除入口。

旧工程的共享变形关键帧继续按原有方式使用；当没有当前皮肤的独立关键帧时，可使用顶点数匹配的旧共享关键帧。新建独立皮肤关键帧后，该皮肤使用自己的轨道。

## 编辑几何、解除关联与删除源

关联期间，目标的几何与权重工具只读，避免误以为正在修改一份独立网格。可选择源进行修改，或在 Setup 点击“解除关联并保留网格”。解除后保留当时的几何和权重；若原先继承变形，也会把对应动画复制为目标自己的变形关键帧。此后源的修改不再传到目标。

删除源附件或源所在皮肤时，依赖它的关联网格会先转成独立网格，并保留其继承动画，避免留下断开的引用。删除占位本身仍会删除占位对应的皮肤内容和动画目标。以上文档修改支持现有撤销、重做和保存位置标记。

改变拓扑后，不再匹配有效目标顶点数量的变形关键帧会被移除，并沿用问题面板的提示和撤销机制。无效源、循环引用及不存在的皮肤目标会阻止保存或导出，不能静默生成残缺画面。
