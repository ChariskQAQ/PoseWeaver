# 从机器人示例到游戏引擎

启动页选择“完整示例：机器人”，或打开 `samples/robot-starter.rig.json`。这是已绑定的完整角色，含 15 根骨骼、12 个插槽、`ocean` / `ember` 两套皮肤、两条腿的 IK，以及 `idle` / `walk` / `wave` 三个动作。图片和音频均为相对路径，保存在同一个 samples 文件夹。

## 1. 先完成一次制作流程

1. 用“文件 → 另存为”保存自己的练习副本，并勾选“收集工程资源”。之后搬移副本时，把旁边的资源文件夹一并复制。
2. 按 Tab 切换 Setup / Animate。Setup 编辑静态骨架，Animate 编辑动作；初学时先不要改动已经绑定的骨架。
3. 在树中展开 root、body、四肢与图片插槽，依次点击观察视口和属性的对应关系。按 F 适配角色；角色太小或被遮住时可重置窗口布局。
4. 展开“皮肤”，只启用 `ocean` 或 `ember` 之一，检查角色配色是否改变。两套皮肤同时启用时，后启用的同名附件会覆盖前一套。
5. 进入 Animate，依次选择 `idle`、`walk`、`wave` 并播放。`wave` 在 0.5 秒带有声音事件，音频开关和本机输出设备会影响听感。

## 2. 修改一个动作

1. 选择 `wave`，暂停并把时间移到约 0.5 秒。
2. 选择骨骼 `forearm_r`，确认自动打关键帧已开启，按 C 旋转手臂。
3. 在时间轴上观察新的旋转关键帧，播放检查动作；使用 Graph 调整曲线。
4. Ctrl+Z 撤销，Ctrl+Y 重做；保存后确认标题的未保存标记消失。
5. 要练习 IK，选择 `walk`，移动 `foot_target_l` 或 `foot_target_r`，观察腿部两节骨骼如何跟随。目标超过腿长时，脚不能继续伸长，这是长度限制。

## 3. 用自己的图片练习绑定

新建另一份工程，把分层 PNG 拖入窗口。按 N 从 root 拖出骨骼，在 Setup 模式把插槽拖到对应骨骼上，先完成刚性部件的跟随关系。需要软变形时，选中图片附件并转为网格，绑定多根骨骼后用 G 涂权重。先用一条手臂验证旋转和变形，再增加其他部件。

机器人示例使用分件 Region 附件，便于检查层级和 IK；它不是复杂蒙皮权重的示例。`arm.png` 的挥手示例包含网格、权重和变形，可单独用来练习软变形。

## 4. 图片、像素效果和普通导出

“视图 → 光源与像素...”可打开点光源、像素化、限色、抖动和描边，并选择 CPU / GPU 效果预览。第一次练习先保持原样，确认基本动作正确后再启用效果。

打开“文件 → 导出图片 / GIF / 视频...”：

- 选择动作、格式、帧率、缩放、抗锯齿与留边，填写输出路径或浏览选择。
- 点击“计算导出尺寸与内存”，先检查每帧尺寸、帧数和缓冲估算。预算不生成文件，修改相关参数后需重算。
- 点击导出后可继续编辑，通过任务窗口取消。任务使用启动时的工程快照。
- 配置按工程记忆；另存为继承配置。未保存工程只在当前会话记忆。
- PNG/JPG 序列旁会生成 `.pwexport.json` 清单。缩短动作再导出时，默认仅清理清单记录且内容未变的多余旧帧。手动改过的帧和未记录的文件保留；需要保留完整旧输出时先复制到别处，或取消勾选清理选项。清单应与序列一起保留。

严格限色和透明度请用 PNG；GIF 会二次限色，JPG 和视频编码可能改变颜色。像素模式固定为 1x 抗锯齿采样。

## 5. 导出到 Godot / Unity

打开“文件 → 导出 Unity / Godot 帧动画...”，选择三个动作；`idle`、`walk` 保持循环，`wave` 可取消循环。用 30 FPS、缩放 1 开始，先计算预算，再导出 `robot.pwframes`。把清单及它引用的整个资源文件夹一起复制到引擎项目。

Godot：复制随包 `integrations/godot/addons/poseweaver`，启用插件后导入资源包，拖入场景会得到原生 `AnimatedSprite2D`；用 `play("walk")` 切换动作。

Unity：安装 `integrations/unity` 插件，导入资源包后拖入场景，用 `PoseweaverPlayer.Play("walk")` 切换动作。Unity 当前仅准备了验收脚本，尚未实机验证；不要把此步骤视为已验收的兼容承诺。

当前接入是烘焙帧动画；游戏中不能直接控制这些骨骼、实时换肤或重算 IK。更详细的安装步骤见 [ENGINE_INTEGRATION.md](ENGINE_INTEGRATION.md)。

声音事件可随视频导出；帧动画资源包不包含事件音频，需要在引擎中另外接入。

## 6. 搬移工程后资源丢失

打开“文件 → 批量重定位资源...”或问题面板中的同名按钮，选择包含素材的目录。后台扫描包括子目录，最多检查 50000 个条目；界面显示扫描数量，可取消或关闭该窗口。取消需等当前文件系统读取返回，网络盘暂时失去响应时可能等待较久。唯一同名匹配会预选；同名冲突需自己选候选，也可选择“跳过”。

检查列表后点击“应用已选匹配”，全部选中文件都能解码后才应用；整批操作可撤销、重做。若工程在扫描后发生了相关变化，重新扫描。该操作只更新工程路径，不移动或改写源文件；完成后保存工程。

## 7. 强制退出后恢复导出

普通图片或视频导出在提交文件前，会把日志及恢复索引写入磁盘。提交途中被强制结束后，再次启动会打开“导出中断恢复”，也可从“文件 → 导出中断恢复...”重新检查。

- “恢复上次完整输出”撤回未完成的这次提交，找回旧输出，包含被清理的旧尾帧；首次导出时撤回已提交的新文件。
- 已写入完成标记的导出保留新输出，按钮仅清理备份。
- 恢复在后台执行，不修改当前工程。输出或备份内容与记录不符时停止，保留现场和问题详情；不要自行删除备份文件夹。
- 可选择“稍后处理”。同目录存在未解决的中断提交时，普通导出会拒绝再次提交，先完成恢复或选用其他输出目录。
- 如果输出在移动硬盘或网络目录中，先重新连接，再点击“重新检查”；暂时找不到目录不会丢弃恢复记录。

恢复索引位于 `%APPDATA%\RigEditor\export-recovery`，备份位于输出旁的 `.poseweaver-export-*` 文件夹。两者都需保留。旧版本导出的中断任务没有日志，无法自动恢复。此流程已经过进程异常退出测试，尚未进行物理断电验收。
