# UI 设计（参考 Spine 编辑器）

参考资料：Spine User Guide 的 User interface / Tools / Tree / Dopesheet / Keys 章节（esotericsoftware.com/spine-ui 等）。
以下只借鉴交互和布局思路，图标与配色均为自绘，不使用 Spine 的素材。

## 布局

```
┌──────────────────────────────────────────────┬──────────────┐
│ SETUP / ANIMATE（点击切换）                    │ 树           │
│                                              │  搜索 / 过滤  │
│                  视口（棋盘格背景）             │  骨架         │
│                                              │   ├ 骨骼层级  │
│ 缩放                                          │   ├ 绘制顺序  │
│ 滑条 ┌工具┐┌变换+数值+K┐┌坐标轴┐┌自动帧┐┌显示┐   │   ├ 动画      │
│      └────┘└──────────┘└──────┘└──────┘└────┘   │   └ 图片      │
├──────────────────────────────────────────────┤──────────────┤
│ Dopesheet（仅 Animate 模式）                   │ 属性 / 权重   │
└──────────────────────────────────────────────┴──────────────┘
```

- 视口是主角，其余视图都是可拖动、可停靠的标签页。
- 主工具栏浮在视口底部，分组：
  1. 工具：姿势 (B)、权重 (G)、建骨骼 (N)、网格 (M)
  2. 变换：旋转 (C)、移动 (V)、缩放 (X)，每行带数值框；Animate 模式下行尾有打帧按钮
  3. 坐标轴：局部 / 父级 / 世界，决定数值框显示什么
  4. 自动关键帧开关
  5. 显示选项：骨骼/图片/网格 的 可见、可选、名称
- 打帧按钮颜色：绿 = 当前帧无关键帧，橙 = 有未打帧的改动，红 = 当前帧有关键帧。
- 自动关键帧关闭时，Animate 模式下的改动先作为“未打帧改动”保留，切换时间会丢弃；按 K 打所有改动。

## 视口

- 右键拖动平移，滚轮缩放；右键单击（不拖动）在当前工具与上一个工具之间切换。
- 左下角竖向缩放滑条，下方“100%”和“适配”按钮。
- 拖动可以从空白处开始，作用于当前选中项（变换工具），这样不需要精确点中小手柄。
- Setup 模式下，鼠标放在选中骨骼的末端可拖动修改骨骼长度。
- 姿势工具：拖骨骼原点 = 移动，拖骨骼其它部位 = 让骨骼指向鼠标。
- Esc 取消选择。

## 树

- 一棵树包含：骨架 → 骨骼层级（骨骼下挂插槽，插槽下挂附件）、绘制顺序、动画、图片。
- 左侧两列：可见性圆点（骨骼/插槽仅编辑器内隐藏；附件圆点 = 当前显示哪个附件；动画圆点 = 当前动画）、
  打帧按钮列（Animate 模式）。
- 顶部搜索框按名称过滤，过滤按钮只显示骨骼/插槽/附件。
- 选中项的属性显示在树下方的“属性”视图，标题行右侧有 重命名 / 删除 按钮。

## Dopesheet

- 工具栏：当前帧、动画选择、播放控制（首帧、上一关键帧、倒放、播放、下一关键帧、末帧）、循环、速度、FPS、锁定。
- 标尺：帧号，有关键帧的帧上画橙色小菱形；青色竖线 = 当前时间；橙色竖线 = 动画结束。
- 行：总览行（动画名）→ 骨骼行（可折叠）→ 属性行（旋转/移动/缩放/附件）。
  关键帧是彩色竖条：旋转绿、移动蓝、缩放红、附件紫；同帧多种类型在汇总行显示白色。
  属性行两帧之间：实线 = 线性，虚线 = 阶梯，数值相同则不画。
- 未锁定时只显示所选骨骼的行（没选骨骼则显示全部有关键帧的骨骼）；锁定后保持当前行。
- 滚轮缩放时间轴，右键拖动平移；拖动关键帧移动时间，右键关键帧弹出删除/曲线菜单。
