# 独立分量关键帧与曲线

进入 Animate 模式，选中已有动画关键帧的骨骼或插槽，再打开 Graph。骨骼显示旋转、移动 X/Y、缩放 X/Y、斜切 X/Y；插槽显示 RGBA。左侧复选框控制显示，点击分量名称选择要编辑的分量。

1. 选中某个分量的关键帧，用预设或黄色手柄调整缓动。X/Y 和 RGBA 的其他分量不再跟着改变。
2. 改变时间后，点击“打所选分量关键帧”，会在当前时间记录该分量当前采样值。它不为其他分量增加关键帧。
3. 拖动关键帧可以独立改变该分量的时间和值；Shift 关闭帧吸附。如果目标时间已有同一分量的关键帧，不覆盖它。目标时间只有其他分量时可以合并，各自数值和缓动保留。
4. “删除所选分量关键帧”只删除当前分量；同一时间其他分量的关键帧保留。上述编辑均可撤销、重做。

例：在移动 X 的第 0、30 帧打帧，移动 Y 在第 0、15、30 帧打帧，就能让角色匀速前进，同时在中间达到跳跃最高点。颜色可让 Alpha 使用阶梯，而 RGB 继续平滑变化。

骨骼属性、自动打帧和 Dopesheet 仍按整个通道操作。Dopesheet 中同一时间的多个分量合为一个通道关键帧；整通道设置曲线会统一该时间各分量的缓动。独立分量通道在 Dopesheet 显示时间点，缓动连线由 Graph 分别显示，避免用一条线误表示多个不同节奏。Graph 用来做独立分量精调。

旧工程继续读取原有曲线，原有 X/Y、RGBA 共用曲线的动画不改变结果。首次使用独立分量时间或缓动后，工程保存为格式 8，需要支持该格式的新版本打开。JSON、二进制、自有运行时、图片和视频导出使用相同求值逻辑。

当前 Graph 仍围绕所选骨骼或插槽编辑；本阶段未增加多对象框选和自动切线手柄。
