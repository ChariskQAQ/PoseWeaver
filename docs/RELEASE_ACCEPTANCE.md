# 发布验收

## 普通图片和视频导出

PNG/JPG 序列、精灵表、GIF、MP4/WebM/AVI/MOV 使用后台任务，进度窗口显示分析、绘制、编码写入和提交阶段，可继续编辑。任务持有启动时的工程、皮肤、参数和物理设置副本，并共享只读图片像素；音频在工作线程独立解码。启动时复制大工程仍有短暂开销。命令行导出保持同步，以退出码报告成功或失败。

普通导出和引擎导出同一时间只运行一个任务。取消在当前帧或编码步骤结束后生效；Windows 的 ffmpeg 进程支持取消并中断阻塞的管道写入。关闭、切换工程会请求取消并等待退出；最终提交阶段不再接受取消。POSIX 视频管道尚未提供进程级中断，正式发布该平台前需补齐。

输出先写在目标目录内的独立临时文件夹。提交前不改变旧文件；提交序列文件时暂存旧文件，失败则回滚。若回滚本身失败，保留备份并在问题详情给出恢复目录。1.0.1/1.0.2 的多文件提交没有跨进程恢复日志；1.0.3 新增下述提交记录与恢复入口。多文件输出仍不能作为单次文件系统原子操作。1.0.1 仅替换这次生成的文件；1.0.2 新增下述可选尾帧清理。

最多 10000 帧、单边最多 16384 像素，绘制及 GIF/精灵表缓冲估算上限 512 MiB。姿态分两遍逐帧计算，不保留全部姿态；GIF 仍需暂存帧，过大时会提前拒绝。预算不包含工程、输入图片、源音频解码缓存、编码器和驱动内存；音频混音缓冲另限 128 MiB。

## 撤销内存预算

“编辑 → 撤销内存预算”提供 32/64/128/256/512 MiB，默认 128 MiB，保存到现有用户设置。撤销与重做共享最多 200 步和同一份预算，完整快照按 JSON 字符串实际容量计算，局部记录计入对象及动态字段容量，不包含当前工程、容器和分配器开销。

达到上限时删除距离当前状态最远的记录，优先保留当前方向的最近操作。单份快照超过预算会被丢弃，问题面板会提示该步无法撤销。裁剪历史或修改预算不改变保存位置；撤销回仍保留的已保存状态时，未保存标记会正确清除。

## 安装验收

源码目录中运行：

```powershell
scripts/verify-installer.ps1 -OldPackage <旧绿色版目录> -NewPackage <新绿色版目录> -IsccPath <ISCC.exe路径>
```

脚本以随机独立 App ID 编译测试安装器，安装到项目 `build/installer-acceptance-*/installed`，依次验证安装、覆盖升级、文件哈希、示例存在、用户设置不变和卸载后用户自建工程保留。测试副本不创建快捷方式、不迁移旧品牌快捷方式，不影响真实 Poseweaver 安装；因此真实 App ID、快捷方式、管理员安装和旧品牌迁移仍需在干净 Windows 环境单独检查。证据日志保留在该目录。安装程序需创建测试专用卸载注册表项，受限沙箱可能需要额外执行权限。

## Unity 验收准备

按本次决定，**不安装 Unity，也不声明 Unity 实测通过**。仅准备验收工程和入口：

```powershell
scripts/verify-unity.ps1 -PrepareOnly
scripts/verify-unity.ps1 -EditorPath <Unity.exe路径>
scripts/verify-unity.ps1 -EditorPath <Unity.exe路径> -BuildPlayer
```

生成工程位于 `build/unity-acceptance`，包含插件源文件和挥手示例。导入/播放入口检查原生精灵资源、帧数、播放/暂停/恢复、循环/非循环、原点和采样过滤；第二入口生成场景并构建 Windows 开发版。脚本要求成功标记和正确退出码，保存导入、播放与构建日志。

尚未实测：Unity 2022.3 LTS / Unity 6 的编译与导入、Windows Player 构建及运行、多页图集、像素资源包的实际导入、重新导入和错误资源拒绝。当前挥手示例不能代替这些用例；准备脚本成功不代表引擎验收成功。

## 1.0.3 范围与结果（2026-10-23）

- 普通导出提交前刷新待写输出、原始/新文件指纹和完整计划到日志；索引保存在用户设置目录。Windows 使用写穿透移动，临时文件夹加进程独占锁，启动检查跳过仍在其他进程使用的事务。渲染阶段退出不会改变旧输出；提交前尚未登记的临时目录可能残留，不能自动认领。
- 启动或“文件 → 导出中断恢复...”显示未处理记录，后台恢复撤回未完成提交；带完成标记的事务只清理备份。恢复先检查全部文件，修改过的输出/备份或无效路径会阻止恢复并保留现场。移动硬盘暂时不可用时保留索引。恢复途中再次结束进程可重试；没有历史日志的旧版导出不在范围内。
- 资源扫描采用图片和事件引用的独立副本，在后台检查最多 50000 个条目，仅收集需要匹配的文件名，显示实际扫描数量，支持取消。取消、关闭窗口或切换工程不会应用扫描结果。系统正在处理的单个目录读取无法被强制中断，关闭应用或切换工程可能等待它返回。
- 普通和引擎导出共享不可变图片像素，重新加载或释放视口图片不会破坏已启动任务；工程仍独立复制。导出前避免重复数据检查，配置未变化时跳过重复磁盘刷新。未改动工程文件格式和撤销内存预算。
- 11 项 CTest 全部通过，新增独立中断恢复进程测试和编辑器性能冒烟测试。覆盖七个中断位置（含恢复途中）、完成标记、用户修改保护、篡改路径拒绝、活动进程跳过、输出盘暂时不可用后重试、正常提交失败回滚、启动发现和后台恢复，以及扫描取消、切换工程丢弃结果和图片快照寿命。
- 性能对照及原始 CSV 见 [PERFORMANCE.md](PERFORMANCE.md)。完整机器人样例也运行实际工程入口；大型测试为固定合成压力样例，尚无生产级用户工程样本。界面检查覆盖中英文、窄窗口、扫描/取消和恢复/清理入口。
- 未进行物理断电、文件系统损坏或 POSIX 平台验收；本次未重复安装生命周期与 Unity Editor 验收。

## 1.0.2 新增范围

- 效果预览缓存只因实际姿态、可见附件几何、资源或效果参数改变而刷新；重命名和无关控件操作不再触发重新合成。仍需计算每帧几何签名，未声明整体帧率提升幅度。
- 普通导出配置保存在 `%APPDATA%\RigEditor\image-exports.json`，按工程完整路径区分，动作按名称恢复，另存为继承配置。配置损坏时保留原文件并在问题面板提示，不阻止工程打开。
- “计算导出尺寸与内存”运行后台分析，不生成输出文件；参数、工程或皮肤改变后隐藏过期结果。内存数字仅表示导出缓冲估算，适用上述排除项和上限。
- PNG/JPG 序列旁生成 `<输出文件名>.pwexport.json`。默认仅清理上次清单拥有、此次不再生成且大小及内容指纹仍匹配的尾帧；修改过的、未记录的文件保留。清理与替换共同回滚；清单损坏则拒绝导出。未带清单的历史输出不会被自动认领。此保护仅针对多余尾帧，本次同名输出仍按正常导出规则替换。
- 批量重定位按文件名递归搜索图片和事件音频，最多检查 50000 个目录条目。唯一匹配预选，同名候选由用户选择；应用前检查工程引用及全部所选文件的解码，成功后作为一整步撤销记录。1.0.2 的扫描在当前线程执行；1.0.3 已移到后台并提供取消。
- 完整机器人示例包含 15 根骨骼、12 个插槽、两套皮肤、腿部 IK、三个动作和声音事件；随包附 [上手教程](GETTING_STARTED.md)。机器人使用刚性分件，软网格练习沿用手臂示例。
